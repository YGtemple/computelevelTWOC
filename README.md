(https://github.com/user-attachments/files/32178364/README.md)# 公益版计算机等级考试刷题系统

一个完全免费、纯前端、单文件的计算机等级考试刷题应用。双击 HTML 即可在浏览器中打开使用，无需安装、无需联网、无需后端服务器。

## 项目定位

本项目致力于为备考计算机等级考试的同学提供一个**开箱即用、功能完整、永久免费**的刷题工具。不同于市面上需要付费解锁、强制登录、充斥广告的刷题软件，本项目所有功能完全开放，所有题目免费使用，任何人可自由传播分享。

## 核心功能讲解

### 一、选择题练习系统

选择题是整个应用的基础模块，支持多种练习模式：

- **顺序练习**：按题库顺序依次答题，优先安排未做过的题目，适合第一轮系统学习
- **随机练习**：从题库中随机抽题，自动避开近期已做过的题目，适合第二轮查漏补缺
- **错题重练**：只练习之前答错的题目，针对性突破薄弱环节
- **科目筛选**：支持 10 个科目一键切换，也可以选择"全部"进行跨科目练习
- **关键词搜索**：输入知识点关键词（如"指针"、"数组"、"Java"），实时检索匹配题目

每道选择题答完后立即显示判分结果，包括：
- 正确答案与你的选择对比
- 题目解析（文字说明）
- 四维详细解析：解题思路、关键知识点、易错点提醒、拓展知识（点击展开）

### 二、操作题考场模式

操作题是本项目的核心特色，针对电脑端设计了还原真实考场的交互模式：

**程序填空题**
- 原始代码中的填空占位符（如 `__1__`、`(1)`）自动转换为输入框
- 考生在输入框中填写答案，完成后点击"提交判分"
- 系统自动对比每个空的答案，显示得分和逐空对比
- 支持"直接看答案"模式，快速背诵

**程序改错题**
- 提供代码编辑器，考生直接在代码中修改错误
- 修改后可提交与参考答案对比
- 标注常见错误类型提示（赋值号与等号混淆、指针缺少解引用等）

**程序设计题**
- 提供代码编辑器，考生编写完整函数实现
- 编写后可查看参考答案和解题思路
- 包含完整的 main 函数和程序结构，不是只截取片段

所有代码均使用原始编码（UTF-8）读取，中文注释无乱码；代码区域使用 `white-space: pre` 保留原始换行，支持横向滚动，不会出现"一行变一列"的显示问题。

### 三、模拟考试系统

模拟考试还原真实考试的完整流程：

- **完整试卷结构**：公共基础 10 题 + 专业知识 30 题 + 操作题 3 道，满分 100 分
- **计时不限时**：记录答题用时，但不强制交卷，适合自主练习
- **考试中可查答案**：模拟考试过程中可以随时查看答案和解析，边做边学
- **操作题导航**：选择题部分结束后可进入操作题部分，支持上一题/下一题切换
- **交卷评分**：选择题自动判分，操作题自评，最终计算总分

### 四、手机端背题模式

应用会自动识别设备类型：

- **电脑端**：进入考场模式，操作题可交互填写、提交判分
- **手机端**：进入背题模式，直接显示答案和解析，适合碎片时间背诵
- 响应式布局，从手机到桌面显示器均能正常显示

### 五、辅助学习模块

- **专项刷题**：按知识点分类练习，逐个突破
- **套题真题**：按年份/套题组织的完整试卷练习
- **大题真题**：操作题专项练习，支持科目和题型筛选
- **知识库**：知识点汇总，随时查阅
- **收藏夹**：收藏重点题目，方便复习
- **错题本**：自动记录答错的题目
- **学习统计**：已做题数、正确率、连续打卡等数据展示

## 技术架构

### 纯前端单文件设计

整个应用是一个独立的 HTML 文件，包含：

- **HTML**：页面结构和布局
- **CSS**：样式和响应式设计，内联在 `<style>` 中
- **JavaScript**：所有交互逻辑，内联在 `<script>` 中
- **题库数据**：以 JSON 数组形式内置在 JS 变量中

这种设计的优势：
- 无需构建工具，无需 npm install
- 无需后端服务器，无需数据库
- 双击即可运行，开箱即用
- 数据完全本地，隐私安全

### 数据存储

- 题库数据：内置在 HTML 文件中，加载时直接读取
- 答题记录：保存在浏览器 `localStorage` 中，刷新不丢失
- 收藏/错题：同样保存在 localStorage

### 代码组织

主要 JS 模块：
- `QUESTIONS`：选择题数据数组
- `BIG_QUESTIONS`：操作题数据数组
- `state`：全局状态管理（当前页面、当前题目、答题记录等）
- `renderQuestion()`：渲染选择题
- `openBig()`：渲染操作题详情
- `startMockExam()`：启动模拟考试
- `handleSearch()`：搜索功能（带 300ms 防抖）
- `switchPage()`：页面切换
