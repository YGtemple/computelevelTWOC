# 公益版二级C语言题库

一个完全免费的计算机二级C语言刷题应用，单文件HTML，双击即可使用，也可直接部署到GitHub Pages。

## 题库规模

- **选择题：3192道**（C语言1530道 + 公共基础 + 其他科目）
- **操作题：157道**（含43套完整题目：填空/改错/编程）
- 覆盖：C语言、公共基础、MS Office、WPS Office、三级Linux

## 核心功能

### 选择题练习
- 顺序练习、随机练习、错题重练
- 按知识点分类、按科目筛选
- 关键词搜索
- 自动判分 + 详细解析（解题思路、关键知识点、易错点提醒、拓展知识）

### 操作题（电脑端考场模式）
- **程序填空题**：占位符变为输入框，填写后提交判分
- **程序改错题**：代码编辑器，修改后提交对比
- **程序设计题**：代码编辑器，编写后对比参考答案
- 完整程序代码，包含main函数和完整结构

### 模拟考试（完整试卷）
- 公共基础10题 + C语言30题 + 操作题3道
- 满分100分（选择40分 + 操作60分）
- 不限制时间，记录答题用时
- 考试中可查看答案和解析
- 操作题自评，计算总分

### 手机端背题模式
- 自动识别设备，手机端直接显示答案和解析
- 响应式布局，适配各种屏幕

### 其他功能
- 专项刷题、套题真题、大题真题
- 知识库、收藏、错题本
- 本地存储答题记录

## 本地使用

直接双击 `index.html` 即可在浏览器中打开使用，无需安装，无需联网。

## 部署到GitHub Pages

### 方法一：GitHub Actions（推荐）

1. 在GitHub新建仓库
2. 将本目录所有文件上传到仓库根目录
3. 打开仓库 **Settings -> Pages**
4. 将构建来源设为 **GitHub Actions**
5. 推送到 main 分支后，工作流会自动发布
6. 部署地址通常为：`https://<用户名>.github.io/<仓库名>/`

### 方法二：直接部署

1. 在GitHub新建仓库
2. 上传 `index.html` 和 `.nojekyll` 到仓库根目录
3. 打开 **Settings -> Pages**
4. Source 选择 `Deploy from a branch`，Branch 选择 `main` / `(root)`
5. 保存后等待部署完成
