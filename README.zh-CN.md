# computelevelTWOC

计算机等级考试题库——题库和刷题界面打包进一个 HTML 文件。

<sub>HTML · 单文件 · 完全离线</sub>

---

## 是什么

一个 `index.html`（约 9.3 MB）同时装着题库和刷题界面。打开就能开始答题。

这里的工程做法是刻意的取舍：把几千道题、样式、逻辑全塞进一个文件。代价是架构很差；回报是用户什么都不需要——不用服务器、不用安装、文件下载后连网都不需要。

## 内容

覆盖计等考试各科目的七千余道题，带浏览器刷题流程。

题库还以 `download/` 下的纯文本 / 结构化数据单独分发，供页面之外复用。

## 配套工具

`tools/` 目录放着围绕题库开发的一些配套脚本，各自的作用见那里。

## 运行

```bash
# 用浏览器打开
start index.html
```

不需要安装，页面直接从磁盘运行。
